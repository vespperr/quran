Place surah audio files here for the "M. Azad" reciter.

File naming: one file per surah — {surah 3 digits}.mp3
Examples:
  001.mp3  = Surah 1 (Al-Fatiha)
  002.mp3  = Surah 2 (Al-Baqarah)
  003.mp3  = Surah 3 (Aal-e-Imran)
  114.mp3  = Surah 114 (An-Nas)

You can put files in either:
  - assets/m.azad/   (this folder), or
  - lib/assets/m.azad/

Supported format: MP3 (recommended).
